📊 Stock Portfolio Dashboard

An Excel-based data analysis project that explores trading volume, average close price, and monthly returns across multiple global companies.  
Built using Python (for data generation), Excel Power Query, Power Pivot, and DAX.  
Open to correction and feedback.

---

🚀 Project Goal

Understand how trading volume and return interact — and where the real risks lie.

This dashboard was created not just to visualize data, but to tell a story and uncover insights for smarter portfolio decisions.

---

🔧 Tools & Features Used

- Python – For generating realistic stock portfolio data  
- Excel Power Query – For cleaning, transforming, and merging datasets  
- Power Pivot – For building data models and relationships  
- DAX – For calculated fields (KPIs like Average Return, Expected Return)  
- PivotTables + Charts – For dynamic visualizations  
- Slicers – For filtering by sector, company, and country  
- Dashboard Design – Focused on usability and storytelling, not just visuals

---

📈 Dashboard Highlights

Here’s what the data quietly revealed:

→ High-volume stocks don’t always give high returns
→ SoftBank had the highest volume, but not the best return  
→ The best-performing company had moderate volume, showing that volume ≠ value  
→ Tech & Healthcare sectors dominate the top returns  
→ High-volume + low return = biggest risk exposure

Most people say:  
“Go for high volume stocks.”

Data says:  
“Balance volume with consistent returns.”

That’s the real value of a dashboard.  
Not just visuals. But direction.

---

🧠 Insights from the Process

From data collection through Python, to cleaning and merging datasets, to emphasizing when to use the average vs the median, each chart was designed with a purpose:

→ Every visual has a story  
→ Every filter (slicer) adds depth  
→ Every step contributed to clearer, smarter analysis
